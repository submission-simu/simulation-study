# simulation-study
Simulation

Run "main_simu.R" to reproduce Table 1 in the manuscript.
Please modify the number of cores for parallel in Line 659 of main_simu.R.
To reproduce Tables 3 and 4 in the supplement, please change the value of rho in Line 17 of main_simu.R.



Use case

Run "real_data.R" to implement the use case analyzed in Section 7 of the manuscript.
Before running this script, please ensure the synthetic dataset "real_data.rdata" is located in the same directory as the R script.
Then, running "real_data.R" will generate the respective results, which are similar to those in Figure 1 and Table 3 of the manuscript.
